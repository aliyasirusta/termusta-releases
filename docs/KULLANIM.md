# Kurulum ve kullanım

1. GitHub Releases üzerinden Universal ZIP’i indir ve aç.
2. `Baglanti.app` dosyasını Uygulamalar klasörüne taşı.
3. Bağlantı’yı aç ve **Sunucu ekle** düğmesine bas.
4. Sunucu adı, adres, kullanıcı ve portu girip kaydet.
5. Sunucuyu seç ve **Terminal’de bağlan** düğmesine bas.

SSH oturumu macOS Terminal’de açılır. Kimlik doğrulama ve sunucu anahtarı denetimini macOS OpenSSH yürütür. Bağlantı yalnızca sunucu profillerini yerelde saklar. Bu sürümün paketi yerel olarak imzalanır ve Apple noter onayı içermez.
